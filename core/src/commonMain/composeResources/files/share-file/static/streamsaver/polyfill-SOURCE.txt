采用 ponyfill 变体，导出 WebStreamsPolyfill，不覆盖宿主原生 Streams 全局。
本项目 StreamSaver 读取 WebStreamsPolyfill.WritableStream 作为缺少原生
WritableStream 时的回退；已有原生 WritableStream 仍由 StreamSaver 优先采用。

已执行 Node VM 检查：来源锁定、导出、原生全局保留、顺序读写、pipeTo、
背压、取消/abort、sink 错误传播、TransformStream、真实 StreamSaver 的
写入/close/abort 与原生优先选择，共12项全部通过。仅浏览器边界的 DOM 和
MessageChannel 使用内存替身；没有声称完成浏览器/Service Worker端到端下载测试。
可复查测试：node third-party/resources/tests/verify_web_streams.cjs。
历史前后核查结果另存，不是运行或生成声明所必需的文件。
