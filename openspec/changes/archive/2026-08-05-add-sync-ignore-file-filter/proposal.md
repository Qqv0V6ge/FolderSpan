## Why

同步任务当前仅提供简单通配符过滤，无法复用项目已有的 Ignore 语法解析能力，也无法表达否定、根路径锚定和递归 glob 等常见规则。为避免用户维护两套不一致的排除清单，同步任务需要能够显式选择并严格应用来源根目录中的标准 Ignore 文件。

## What Changes

- 在同步任务编辑页的简单过滤规则上方新增默认关闭的高级 Ignore 设置区，并仅允许多选来源根目录中实际存在的标准 Ignore 文件；高级 Ignore 开关行与相邻的“包含子目录”“同步空目录”使用相同的平面布局和左右边界，文件入口也不增加水平内缩，仅用垂直间距维持可读性；整体不显示卡片边框或独立容器背景，且只有开关控件自身可以启停功能；没有候选文件时隐藏选择入口及其图标，来源发生变化时立即清空全部选择。
- 高级 Ignore 与现有简单过滤规则叠加，任一规则命中即从同步计划中排除。
- 同步执行在任何目标写入前严格读取所选 Ignore 文件；文件缺失、过大或不可读取时终止本次运行。
- Ignore 规则适用于 Local、Device 和 Network 目录来源；忽略目录会剪枝，所选 Ignore 文件自身不传输，被忽略目标路径不会被删除型同步流程清理。
- 目录监听同步存在时复用相同过滤器，并在所选 Ignore 文件变化后重新加载规则和校准。
- **BREAKING**：直接调整开发期 `SyncTask` 持久化与配置快照模型，不提供旧任务文件、旧 ProtoBuf 或旧 Pro 快照兼容与迁移。

## Capabilities

### New Capabilities

无。

### Modified Capabilities

- `manage-sync-tasks`: 增加任务级 Ignore 文件配置、严格读取、联合过滤、删除保护和页面交互要求。

## Impact

- 影响同步任务模型、任务文件持久化及 Pro 配置快照字段。
- 影响同步来源扫描、跨端 Ignore 文件读取、删除保护和目录监听校准。
- 影响共享同步编辑页、简体中文与英文资源以及公共和共享 UI 测试。
- 复用现有 `IgnoreMatcher`、`ResolvedIgnoreMatcher`、受支持 Ignore 文件名列表和跨端目录读取能力，不新增外部依赖。
