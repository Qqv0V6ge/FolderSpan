## MODIFIED Requirements

### Requirement: 平台提供剪贴板文件粘贴入口
系统 SHALL 在 Desktop、Android、iOS 和 Web 上提供符合平台习惯的剪贴板文件粘贴入口，并且该入口 SHALL 仅在用户主动触发时读取剪贴板；Desktop/Web 的非编辑态粘贴快捷键 SHALL 优先处理真实文件载荷，并在不存在真实文件载荷时把文本快照转交给主动粘贴文字分流。

#### Scenario: 通过显式操作粘贴文件
- **WHEN** 用户在文件浏览上下文触发“粘贴剪贴板文件”操作
- **THEN** 系统读取当前剪贴板中的可导入文件载荷
- **AND** 系统开始处理所有可读取的文件条目

#### Scenario: 通过桌面快捷键粘贴文件
- **WHEN** 用户在 Desktop 或 Web 的文件浏览上下文按下 `Ctrl+V` 或 `Cmd+V`
- **AND** 当前焦点不在文本输入、文件编辑器或其他需要文本粘贴的控件中
- **AND** 剪贴板包含真实文件或图片载荷
- **THEN** 系统触发剪贴板文件粘贴

#### Scenario: 非编辑态快捷键转交文本
- **WHEN** 用户在 Desktop 或 Web 的文件浏览上下文按下 `Ctrl+V` 或 `Cmd+V`
- **AND** 当前焦点不在可编辑控件中
- **AND** 剪贴板不包含真实文件或图片载荷但包含文字
- **THEN** 系统不创建当前目录文件复制任务
- **AND** 系统把同一次粘贴捕获的文字快照交给主动粘贴文字分流
- **AND** 独立 URL 显示下载设置，而不是执行“从剪贴板打开”的元数据入列行为

#### Scenario: 文本编辑上下文保留系统粘贴
- **WHEN** 用户在文本输入、文件编辑器或其他可编辑控件中按下粘贴快捷键
- **THEN** 系统 MUST NOT 将该快捷键作为文件粘贴或 URL 下载处理
- **AND** 控件继续接收平台默认的文本或富内容粘贴行为
