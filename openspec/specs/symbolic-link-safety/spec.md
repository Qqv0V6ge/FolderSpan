# symbolic-link-safety Specification

## Purpose
为本地、特权访问和远程文件系统提供统一的符号链接安全语义，确保递归操作不会越过用户选择或角色授权的根目录，不会递归删除链接目标，并且在大型目录上以有界内存持续运行。
## Requirements
### Requirement: 文件元数据必须显式描述符号链接

文件元数据模型和仍受支持的传输映射 MUST 区分符号链接与普通文件或目录。新增标识 MUST 保持旧数据可反序列化；当递归调用方无法确认远端是否支持链接元数据时，调用方 MUST 停止递归或使用服务端提供的安全递归接口，不得把“未知”当作可递归目录。

#### Scenario: 本地目录列举符号链接

- **WHEN** 目录中包含指向文件或目录的符号链接
- **THEN** 返回的元数据将该条目标记为符号链接
- **AND** 条目仍可展示，但不得仅因其目标是目录而将其当作普通目录递归

#### Scenario: 读取旧版本持久化数据

- **WHEN** 应用读取没有符号链接字段的旧版本数据
- **THEN** 反序列化保持兼容
- **AND** 任何需要继续远程递归的流程先确认对端的链接安全能力，否则安全终止

### Requirement: 递归操作默认不得跟随符号链接

目录统计、复制、移动、删除、拖拽导入、归档和通用遍历 MUST 将符号链接视为叶子条目，不得将其目标加入待遍历队列。遍历状态 MUST 与目录深度或待处理队列有界，不得为统计目的永久保留全部文件元数据或路径。

#### Scenario: 统计目录内指向根外的链接

- **WHEN** 被统计目录包含指向选择根之外大型目录的符号链接
- **THEN** 统计不会进入链接目标
- **AND** 结果不会包含目标目录的大小或子项数量

#### Scenario: 符号链接形成祖先循环

- **WHEN** 目录树中的符号链接指向自身或任一祖先
- **THEN** 遍历把链接作为叶子处理并在有限时间内结束
- **AND** 内存占用不会随重复路径无限增长

#### Scenario: 统计大型目录

- **WHEN** 目录包含大量普通文件和子目录
- **THEN** 统计以流式方式累计大小和数量
- **AND** 已处理条目的完整元数据不会全部常驻内存

### Requirement: 递归删除必须采用不跟随链接的语义

所有本地及特权递归删除实现 MUST 在检查目录类型前识别符号链接。删除符号链接 MUST 只删除链接目录项本身；删除包含符号链接的普通目录 MUST 不读取、不修改、不删除链接目标中的内容。

#### Scenario: 删除指向根外目录的链接

- **WHEN** 用户删除一个指向根外目录的符号链接
- **THEN** 应用只删除符号链接本身
- **AND** 目标目录及其内容保持不变

#### Scenario: 删除包含目录链接的目录树

- **WHEN** 用户递归删除一个普通目录，且其中包含指向外部目录的链接
- **THEN** 应用删除普通目录树和链接目录项
- **AND** 不进入或删除外部目标的任何子项

### Requirement: 受根目录约束的访问必须校验解析边界

任何以共享根、角色授权根或用户选择根限制访问的操作 MUST 在访问前验证最终目标和所有可遍历父组件没有通过符号链接逃出该根。边界判断 MUST 使用路径组件语义及平台解析后的规范路径，不得使用简单字符串前缀比较。

#### Scenario: 授权根内链接指向根外

- **WHEN** 请求路径的表面文本位于授权根内，但中间组件是指向根外的符号链接
- **THEN** 操作在读取、写入、列举、重命名或删除之前被拒绝

#### Scenario: 相似名称不属于授权根

- **WHEN** 授权根为 `/data/share` 且请求目标为 `/data/share-backup/file`
- **THEN** 路径组件边界判断拒绝该目标
